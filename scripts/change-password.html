Generar hash bcrypt

Herramienta standalone para crear el passwordHash que va en dashboard/auth.json. La password nunca sale del navegador.

⚠ Este archivo (auth.json) es público en GitHub Pages. Cualquiera puede descargar el hash. Usa una password de ≥20 caracteres aleatorios para que sea inviable hacer brute-force offline.
—
Para aplicar:
  1. Genera el hash arriba.
  2. Abre dashboard/auth.json en el repo.
  3. Reemplaza el valor de users[0].passwordHash por el nuevo hash.
  4. Commit + push. GitHub Pages redeploya automáticamente.
  5. Guarda la password en tu password manager. No la commitees a ningún lado.
