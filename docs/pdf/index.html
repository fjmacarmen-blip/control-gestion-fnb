Cómo guardar el PDF

  1. Abre el documento haciendo click en «Abrir →».
  2. Pulsa el botón verde 🖨️ Guardar como PDF (esquina superior derecha) o usa Ctrl + P.
  3. En el diálogo de impresión, elige destino «Guardar como PDF».
  4. En opciones, deja el formato A4 y márgenes predeterminados. Activa Gráficos de fondo si Chrome lo pide.
  5. Listo. PDF profesional sin instalar nada.
